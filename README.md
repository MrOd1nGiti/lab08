## Описание программ

- `collections_lab.py` - модуль, реализующий функции для подсчета частоты слов в тексте, поиска общих и уникальных тем с использованием множеств, а также агрегации данных и фильтрации записей по категориям. Содержит демонстрационную точку входа (`main`).
